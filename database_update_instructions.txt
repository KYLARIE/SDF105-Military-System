DATABASE UPDATE INSTRUCTIONS
==========================

The error message "Column not found: 1054 Unknown column 'email' in 'field list'" indicates that your database is missing the columns we added to the profile page. Here's how to fix it:

OPTION 1: Using phpMyAdmin (Recommended)
----------------------------------------
1. Open your web browser and navigate to phpMyAdmin (usually http://localhost/phpmyadmin)
2. Login with your MySQL credentials (usually username: root, password: empty)
3. Select the "military" database from the left sidebar
4. Click on the "SQL" tab at the top
5. Copy and paste the following SQL commands:

```sql
-- Add profile_photo column
ALTER TABLE `admins` ADD COLUMN `profile_photo` VARCHAR(255) DEFAULT NULL;

-- Add role column
ALTER TABLE `admins` ADD COLUMN `role` VARCHAR(100) DEFAULT 'Administrator';

-- Add email column
ALTER TABLE `admins` ADD COLUMN `email` VARCHAR(255) DEFAULT NULL;

-- Add phone column
ALTER TABLE `admins` ADD COLUMN `phone` VARCHAR(50) DEFAULT NULL;

-- Add department column
ALTER TABLE `admins` ADD COLUMN `department` VARCHAR(100) DEFAULT 'IT Department';
```

6. Click the "Go" button to execute the SQL commands
7. You should see a success message for each command

OPTION 2: Using MySQL Command Line
---------------------------------
1. Open Command Prompt or PowerShell
2. Navigate to your MySQL bin directory (usually C:\xampp\mysql\bin)
3. Run the following command to connect to MySQL:
   ```
   mysql -u root -p
   ```
   (Press Enter when prompted for password if it's empty)
4. Select the military database:
   ```
   USE military;
   ```
5. Run each of these commands one by one:
   ```
   ALTER TABLE `admins` ADD COLUMN `profile_photo` VARCHAR(255) DEFAULT NULL;
   ALTER TABLE `admins` ADD COLUMN `role` VARCHAR(100) DEFAULT 'Administrator';
   ALTER TABLE `admins` ADD COLUMN `email` VARCHAR(255) DEFAULT NULL;
   ALTER TABLE `admins` ADD COLUMN `phone` VARCHAR(50) DEFAULT NULL;
   ALTER TABLE `admins` ADD COLUMN `department` VARCHAR(100) DEFAULT 'IT Department';
   ```
6. Exit MySQL by typing:
   ```
   exit;
   ```

After completing these steps, your database will have all the necessary columns, and the profile page should work correctly.
